## Qué vas a construir

Un editor de imágenes con IA: el usuario sube una foto, la aplicación sugiere ediciones automáticamente, y cada edición se ejecuta en un **Managed Agent** que corre un script de Python dentro de un **sandbox remoto en la nube de Google**, el cual llama a Gemini para transformar la imagen.
