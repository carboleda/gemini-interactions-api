# Editor de Imágenes — Proyecto base del codelab

Este es el punto de partida del codelab **"Construye un Editor de Imágenes usando Interactions API y Managed Agents"**.

El servidor, el frontend y la mayor parte de la lógica ya están completos. Faltan 6 bloques de código en `lib/geminiAgent.js` y `scripts/edit_image.py`, marcados con comentarios `TODO (Paso N)`. El codelab te da el código exacto de cada bloque, explica qué hace y en qué línea va.

## Arranque rápido

1. Copia `.env.example` a `.env` y coloca tu `GEMINI_API_KEY` (genera una gratis en [Google AI Studio](https://aistudio.google.com/api-keys)).
2. `npm install`
3. `npm run dev`
4. Sigue el codelab paso a paso — cada `TODO` desbloquea la siguiente parte de la app.
